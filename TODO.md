# Entregas

- [ ] O painel `admin-noticias.html` deve permitir editar o texto completo com negrito, itálico, sublinhado, títulos, listas, alinhamento, tamanho de fonte, cor, links e limpeza de formatação.
- [ ] O editor deve permitir inserir imagens no corpo da notícia por upload, usando o Firebase Storage e mantendo o fluxo de autenticação existente.
- [ ] O conteúdo formatado deve ser salvo no campo `conteudo` da notícia e continuar compatível com notícias antigas em texto puro.
- [ ] A página pública da notícia deve renderizar o HTML permitido com segurança, sem executar scripts, eventos ou URLs perigosas.
- [ ] O editor e o conteúdo público devem permanecer utilizáveis em telas pequenas.
